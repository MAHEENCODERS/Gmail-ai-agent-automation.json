# Gmail AI Agent Automation

## Workflow
Gmail Trigger → AI Agent → Gmail Reply

## AI Model
Groq Chat Model

## Tools
- Google Sheets
- Gmail

## Purpose
This workflow receives Gmail messages, processes them through an AI Agent using the Groq Chat Model, reads relevant information from Google Sheets, and sends an automated reply through Gmail.
